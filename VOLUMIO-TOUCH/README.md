# Earlier Volumio Touch development

For the current project, go to **[PIXIS Volumio Touch for Volumio 4](https://github.com/PIXISREPO/VOLUMIO-4-TOUCH)**.

This folder preserves earlier Python touchscreen work. It is not required by the current foonerd-based project.

- `PIXIS-TOUCH/`: earlier touch-capture notes, artwork and mute experiments.
- `Waveshare/`: earlier Python display/touch scripts and setup/uninstall files.

These paths are retained for historical references. Follow the separate Volumio 4 repository for a new build.
